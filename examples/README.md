# Examples

One working applet per shape, and the templates a new applet starts from: the MCP `applet_create` takes one by name and `templates_list` describes them, and the editor's New applet dialog lists them. They are not packages in the workspace, so `vp run check` does not typecheck them: `npm:` imports and `@std` only resolve inside the bundler script.

| Example | Shape | Shows |
| --- | --- | --- |
| `basic-html` | web page | `index.html` and `style.css` imported as text and served by path, [Pico](https://picocss.com) for styling, a `client/main.ts` script served at `/main.js` |
| `preact-app` | web app | a [Hono](https://hono.dev) router on the server with `export const fetch = app.fetch`, a Preact page with Tailwind's classes generated by [UnoCSS](https://unocss.dev) at run time |
| `sql-form` | web app with storage | the same, with a form posting to an `/api` route that writes and reads `sql` |
| `chat` | web app with AI | `ai.stream` piped to the browser as a streamed response, an `npm:` dependency on both sides, and a `shared/` module |
| `mailbox` | web app with mail | an `inbox` export, `email.send`, and a Preact client over `/api` routes; turn email on in its settings after the push |

After changing one, `vp run templates` embeds them all into `packages/api/src/templates.json`, and a test in `packages/cli` fails until that has been run. Deploy one with `vp run push --visibility public examples/preact-app`; `vp run ship` pushes `preact-app` and `mailbox` as the check after a platform change. `chat` spends the OpenRouter key, so push it private. `vp run remove <name>` deletes one from the platform.
